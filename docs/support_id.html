Pertanyaan Umum

Pertanyaan dan jawaban umum, dikelompokkan berdasarkan topik.

Dasar-dasar

Dari mana saya bisa membuka file PDF?

Gunakan pemilih file yang ditampilkan saat peluncuran untuk memilih a PDF dari perangkat Anda atau iCloud Drive.

Menu atau penggeser tidak terlihat.

Ketuk gambar PDF untuk mengaktifkan toolbar, cari bilah, dan penggeser.

Bagaimana cara berpindah antar halaman?

Gesek pada layar, atau tampilkan menu dan gunakan penggeser di bagian bawah layar.

Melihat dan Kontrol

Apakah ini mendukung PDF kanan ke kiri?

Ya. Aplikasi membaca Arah PDF dan PageLayout pengaturan dan menampilkan halaman yang sesuai urutan pembacaan dari kanan ke kiri atau kiri ke kanan.

Bisakah saya beralih antara tampilan satu halaman dan dua halaman?

Ya. Anda dapat mengubah tampilan dari tampilan pengaturan, termasuk bagaimana halaman sampul ditangani.

Bisakah saya memindahkan PDF yang diperbesar?

Setelah mencubit untuk memperbesar, tekan lama dan seret ke pindahkan area yang terlihat. Ketuk dua kali untuk mengatur ulang zoom.

Apa yang harus saya lakukan jika tampilan terlihat buram?

Aktifkan Kualitas Tinggi atau Ketajaman di pengaturan. Opsi ini mungkin meningkatkan beban rendering pada beberapa perangkat perangkat.

Data dan Keamanan

Apakah file PDF dikirim ke luar perangkat?

Tampilan PDF diproses di perangkat. Aplikasi tidak menyertakan fitur yang mengunggah PDF ke server eksternal untuk diproses.

Bisakah saya membuka PDF yang dilindungi kata sandi?

Ketika PDF memerlukan kata sandi pengguna, aplikasi akan muncul dialog kata sandi. Jika kata sandi membuka kunci PDF, membaca berlanjut.

Apakah pembelian dalam aplikasi diperlukan?

Tidak. Tip adalah pembelian dukungan opsional. Aplikasinya fitur membaca dapat digunakan tanpa membeli tip.

Lingkungan dan Masalah

Apa yang harus saya lakukan jika PDF tidak terbuka?

Pastikan file tersebut berbentuk PDF, tidak rusak, dan telah diunduh sepenuhnya dari iCloud Drive.

Bagaimana jika halaman kiri dan kanan tidak sesuai harapan?

Periksa arah, tampilan dua halaman, tampilan sampul, dan pengaturan mode penutup. Beberapa PDF mungkin memerlukan penyesuaian manual tergantung pada metadatanya.

Bisakah saya mengatur ulang pengaturannya?

Ya. Pilih Atur Ulang dari opsi di Pengaturan ke pulihkan pengaturan tampilan default dan tutup dokumen saat ini.

Pemecahan masalah

Jika aplikasi tidak berfungsi seperti yang diharapkan, periksa item berikut secara berurutan.

Mulai ulang aplikasi

Jika tampilan rusak sementara atau aplikasi berhenti merespons, keluar dari aplikasi dan buka lagi.

Periksa file PDF

Coba buka PDF lain. Jika hanya satu file yang gagal, mungkin saja rusak, tidak diunduh sepenuhnya, atau dilindungi oleh a kata sandi yang berbeda.

Tinjau pengaturan tampilan

Mengubah tampilan dua halaman, tampilan sampul, arah, atau mode sampul dapat meningkatkan urutan halaman dan navigasi.

Atur ulang pengaturan

Gunakan Reset di Pengaturan untuk kembali ke default. Itu PDF yang sedang dibuka akan ditutup setelah reset.

Perbarui iOS/iPadOS dan aplikasinya

Perbarui OS dan aplikasi Anda ke versi terbaru. Lingkungan yang lebih lama mungkin memiliki integrasi atau tampilan file masalah.
