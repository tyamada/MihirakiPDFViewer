Kebijakan Privasi

Kebijakan Privasi

MihirakiPDFViewer adalah aplikasi untuk membaca PDF dengan nyaman perangkat Anda. Halaman ini menjelaskan informasi apa saja yang dimiliki aplikasi menangani dan bagaimana informasi tersebut digunakan.

Ringkasan

Pendekatan privasi dasar aplikasi.

Konten PDF tidak dikirim

Tampilan, pencarian, deteksi halaman, dan pemrosesan terkait untuk PDF yang dipilih ditangani di perangkat.

Tidak ada iklan atau SDK analitik

Aplikasi ini tidak menyertakan SDK pihak ketiga untuk penyampaian iklan atau analisis perilaku.

Pembelian ditangani oleh Apple

Pembelian dalam aplikasi diproses melalui StoreKit Apple. Aplikasi tidak secara langsung menerima informasi pembayaran.

Informasi yang Ditangani Aplikasi

Informasi yang mungkin digunakan oleh setiap fitur.

File PDF

Aplikasi ini membuka file PDF yang dipilih dengan pemilih file. Teks PDF, metadata, dan informasi halaman digunakan untuk fitur tampilan.

  • File PDF tidak diunggah ke server eksternal.
  • PDF di iCloud Drive dimuat sesuai dengan perilaku sistem Apple.
  • Kata sandi untuk PDF yang dilindungi hanya digunakan untuk membuka kunci dokumen.

Pengaturan Aplikasi

Pengaturan tampilan, pengaturan sampul, tampilan dua halaman, aplikasi pengaturan ikon, dan preferensi serupa dapat disimpan pada perangkat.

  • Pengaturan digunakan untuk memulihkan perilaku aplikasi.
  • Pengaturan tidak dikirim ke server pengembang.

Istilah Pencarian

Teks yang dimasukkan dalam pencarian PDF digunakan untuk mencari di dalam membuka PDF. Istilah pencarian tidak dikirim ke eksternal layanan.

Pembelian Dalam Aplikasi

Status pembelian tip dapat digunakan untuk UI pasca pembelian dan ikon aplikasi berubah.

  • Informasi pembayaran dikelola oleh Apple.
  • Pengembang tidak menerima nomor kartu kredit atau rincian pembayaran serupa.

Pertanyaan Dukungan

Jika Anda menghubungi dukungan melalui Masalah GitHub atau email, informasi yang Anda kirim mungkin ditinjau seperlunya membalas atau menyelidiki masalah tersebut.

  • Jangan kirim file PDF atau isinya. Baca petunjuk laporan dan gambar di bawah sebelum menghubungi dukungan.
  • Model perangkat, versi OS, versi aplikasi, dan langkah-langkah reproduksi membantu penyelidikan.

Berbagi dengan Pihak Ketiga

Informasi yang Anda pilih untuk dibagikan atau dikirim ke dukungan diterima oleh penerima pilihan Anda dan dapat disimpan di sana. Pembelian StoreKit dan iCloud Drive mengikuti penanganan Apple. Unduhan contoh dan tautan eksternal menghubungi operator layanan; kebijakan privasi mereka dan tujuan berbagi yang Anda pilih berlaku. Aplikasi tidak mengirim diagnostik otomatis kepada pengembang.

Keamanan

File dan pengaturan PDF hanya ditangani sesuai kebutuhan aplikasi.

Informasi yang Anda Kelola

File PDF dan kata sandi dikelola oleh perangkat Anda, iCloud Drive, atau lokasi penyimpanan yang Anda gunakan. Jika Anda menangani PDF sensitif, aktifkan kode sandi perangkat, biometrik otentikasi, dan perlindungan akun iCloud.

Perubahan Kebijakan

Kebijakan privasi ini dapat diperbarui bila diperlukan.

Pemberitahuan Perubahan

Perubahan penting akan diumumkan di halaman ini atau di aplikasi. Versi terbaru selalu tersedia di halaman ini.

Diagnostik di perangkat dan log aplikasi

Hasil diagnostik disimpan dalam memori layar saat ini. Jika Anda memilih berbagi, teks mencakup waktu pengujian, nama dan pengenal model (bukan ID unik perangkat), versi OS dan aplikasi, memori total dan tersedia, serta hasil selain pemeriksaan ruang penyimpanan kosong. Log berisi jenis peristiwa, waktu, jumlah, dan durasi pemrosesan. Log yang dapat dibaca dan dibagikan di aplikasi dibatasi 2.000 entri; entri lebih dari 24 jam dihapus saat log dibaca atau dicatat, bukan oleh pengatur waktu ketika aplikasi berhenti. Log sistem mengikuti aturan OS. Hasil dan log tidak dikirim otomatis.

Kontak

Untuk pertanyaan privasi atau permintaan penghapusan, silakan hubungi dukungan.

Metode Kontak

Gunakan Masalah GitHub atau email. Saat memposting di tempat umum, jangan sertakan informasi pribadi atau konten PDF.

Buka Halaman Dukungan

Kebijakan Privasi

Buka Kebijakan Privasi di bagian atas Pengaturan atau di Informasi Aplikasi. Tersedia sebelum memilih PDF dan saat membaca, tanpa pembelian atau login.

Ruang penyimpanan kosong hanya ditampilkan di perangkat ini. Teks diagnostik yang dibagikan tidak menyertakan pemeriksaan ruang, nilainya, atau pengaruhnya pada hasil keseluruhan. Log dapat memuat durasi pemrosesan, tetapi tidak memuat waktu aktif sistem mentah.

Pemulihan bacaan menyimpan bookmark dokumen, halaman, pengaturan tampilan, dan teks pencarian secara lokal; kata sandi PDF tidak disimpan. Unduhan contoh menghubungi GitHub Releases saat diminta. Membuka kebijakan ini atau GitHub Issues juga menghubungi situs eksternal yang pengelolanya dapat menerima alamat IP dan informasi permintaan. Laporan dibagikan ke tujuan yang Anda pilih. Layanan eksternal memiliki kebijakan privasi masing-masing.

Tampilan dan pencarian PDF diproses di perangkat. Pemulihan membaca menyimpan penanda dokumen, posisi halaman, teks pencarian dan opsi tampilan secara lokal, tetapi tidak menyimpan kata sandi PDF. Menutup dokumen atau mengatur ulang pengaturan menghapus catatan pemulihan, bukan PDF atau log diagnostik. Beberapa PDF yang diimpor disalin ke penyimpanan Documents aplikasi. Untuk menghapus data lokal, gunakan penghapusan aplikasi pada OS, bukan penghapusan aplikasi sementara yang mempertahankan data. Dokumen asli eksternal dan salinan yang sudah dibagikan tidak ikut dihapus. Tidak ada tombol khusus untuk menghapus log.

Saat Anda membuka daftar contoh, aplikasi memeriksa GitHub untuk mengetahui apakah JSON katalog terbaru tersedia. Jika pembaruan gagal, aplikasi menggunakan daftar tersimpan terakhir yang valid atau daftar bawaan aplikasi. File PDF hanya diunduh jika Anda memilih untuk mengunduhnya. Permintaan katalog menghubungi raw.githubusercontent.com; unduhan PDF menghubungi GitHub Releases. Layanan ini dapat menerima alamat IP dan informasi permintaan Anda.

Informasi dukungan dan penyimpanan

Informasi dukungan hanya digunakan untuk membalas, menyelidiki masalah, dan melakukan perbaikan teknis pada kinerja. Kami tidak meminta nama asli. Jika nama tampilan pengirim memuat nama asli, nama itu disimpan hanya di email asli selama diperlukan untuk balasan dan penyelidikan; tidak disalin ke Google Sheets per kasus atau catatan perbaikan.

Kami biasanya tidak meminta tangkapan layar. Hanya jika teks saja tidak dapat mereproduksi masalah dan gambar diperlukan, kami menerimanya di tyamada.support@gmail.com. Sebelum mengirim, sembunyikan isi PDF, nama file, nama orang, notifikasi, dan informasi lain yang tidak diperlukan untuk penyelidikan. Gambar pada prinsipnya ditangani di dalam email asli. Sheets per kasus hanya berisi temuan yang diperlukan untuk penyelidikan, bukan gambar.

Nama atau nama pengguna penulis GitHub tidak disalin ke Sheets per kasus atau catatan perbaikan. Tautan ke Issue asli disimpan di Sheet kasus hanya jika diperlukan untuk membalas atau menyelidiki. Selama penulis dapat ditemukan melalui tautan tersebut, catatan itu tetap dapat dikaitkan dengannya. Jangan unggah informasi pribadi, file PDF atau isinya, nama file, maupun tangkapan layar ke Issue publik.

Postingan publik di GitHub berbeda dari email dan catatan kasus yang kami kelola. Menghapus tautan kasus kami tidak menghapus Issue publik. Kami tidak menjamin penghapusan postingan atau salinan layanan di luar kendali kami. Laporan dan referensi kasus yang dapat ditelusuri kembali ke pengirim tidak diperlakukan sebagai anonim.

Titik awal dan tenggat penghapusan

A. Email asli, termasuk nama asli yang ditampilkan, gambar dan salinan penyelidikan: kasus dinyatakan selesai bila sudah ada balasan atau kesimpulan penyelidikan dan pengembang memastikan tidak ada pekerjaan tersisa. Tidak adanya balasan saja tidak otomatis menutup kasus. Tenggat diperiksa setiap minggu. Penghapusan dimulai sekitar 60 hari setelah penyelesaian, dan penghapusan catatan yang dapat dikelola, termasuk Sampah terkait, dikonfirmasi dalam 90 hari. Masa 60 hari bukan batas minimum penyimpanan; permintaan penghapusan lebih awal tidak menunggu tenggat normal.

B. Sheets per kasus, temuan, tautan Issue, serta catatan penerimaan dan penghapusan: penghapusan file kasus dan catatan serta referensi terkait dikonfirmasi dalam 90 hari setelah penghapusan informasi asli selesai. Menghapus baris atau sel saja tidak cukup. Ini tidak memperpanjang A atau mengizinkan pemindahan data asli ke catatan ini. Issue publik yang masih tersedia tidak otomatis memperpanjang tenggat catatan kasus kami.

C. Catatan perbaikan yang digeneralisasi hanya menyimpan penyebab dan ringkasan perbaikan, tanpa nama, gambar, URL postingan, ID kasus, atau informasi lain yang dapat ditelusuri ke laporan asli. Catatan ini bukan tempat penyimpanan pengganti untuk A atau B.

Pengecualian hanya untuk penyelidikan yang berlanjut atau keperluan hukum. Alasan, cakupan, dan kondisi berakhir dicatat dan ditinjau paling lambat setiap 30 hari serta saat penyelidikan berakhir. Setelah kebutuhan itu berakhir, penghapusan biasanya dikonfirmasi dalam 30 hari, atau pada tenggat awal 90 hari jika masih berlaku dan lebih awal. Pembukaan kembali atau pengecualian tidak otomatis mengatur ulang tenggat. Perhitungan menggunakan hari kalender di Asia/Tokyo.

Tenggat ini berlaku untuk catatan yang dapat dikelola pengembang. Penghapusan melalui antarmuka layanan tidak menjamin penghapusan fisik salinan pemulihan internal penyedia atau cadangan perangkat dalam periode yang sama. Salinan dan batas penghapusannya berbeda dari catatan di bawah kendali kami. Menghapus log aplikasi lokal tidak menghapus laporan yang sudah dikirim.

Untuk pertanyaan atau permintaan penghapusan, hubungi tyamada.support@gmail.com. Berikan hanya informasi yang diperlukan untuk mengidentifikasi kasus terkait; jangan mempostingnya secara publik.
