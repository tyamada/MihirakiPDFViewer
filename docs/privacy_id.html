Kebijakan Privasi

Kebijakan Privasi

MihirakiPDFViewer adalah aplikasi untuk membaca PDF dengan nyaman perangkat Anda. Halaman ini menjelaskan informasi apa saja yang dimiliki aplikasi menangani dan bagaimana informasi tersebut digunakan.

Ringkasan

Pendekatan privasi dasar aplikasi.

Konten PDF tidak dikirim

Tampilan, pencarian, deteksi halaman, dan pemrosesan terkait untuk PDF yang dipilih ditangani di perangkat.

Tidak ada iklan atau SDK analitik

Aplikasi ini tidak menyertakan SDK pihak ketiga untuk penyampaian iklan atau analisis perilaku.

Pembelian ditangani oleh Apple

Pembelian dalam aplikasi diproses melalui StoreKit Apple. Aplikasi tidak secara langsung menerima informasi pembayaran.

Informasi yang Ditangani Aplikasi

Informasi yang mungkin digunakan oleh setiap fitur.

File PDF

Aplikasi ini membuka file PDF yang dipilih dengan pemilih file. Teks PDF, metadata, dan informasi halaman digunakan untuk fitur tampilan.

  • File PDF tidak diunggah ke server eksternal.
  • PDF di iCloud Drive dimuat sesuai dengan perilaku sistem Apple.
  • Kata sandi untuk PDF yang dilindungi hanya digunakan untuk membuka kunci dokumen.

Pengaturan Aplikasi

Pengaturan tampilan, pengaturan sampul, tampilan dua halaman, aplikasi pengaturan ikon, dan preferensi serupa dapat disimpan pada perangkat.

  • Pengaturan digunakan untuk memulihkan perilaku aplikasi.
  • Pengaturan tidak dikirim ke server pengembang.

Istilah Pencarian

Teks yang dimasukkan dalam pencarian PDF digunakan untuk mencari di dalam membuka PDF. Istilah pencarian tidak dikirim ke eksternal layanan.

Pembelian Dalam Aplikasi

Status pembelian tip dapat digunakan untuk UI pasca pembelian dan ikon aplikasi berubah.

  • Informasi pembayaran dikelola oleh Apple.
  • Pengembang tidak menerima nomor kartu kredit atau rincian pembayaran serupa.

Pertanyaan Dukungan

Jika Anda menghubungi dukungan melalui Masalah GitHub atau email, informasi yang Anda kirim mungkin ditinjau seperlunya membalas atau menyelidiki masalah tersebut.

  • Jangan mengirim konten PDF atau informasi pribadi kecuali diperlukan.
  • Model perangkat, versi OS, versi aplikasi, dan langkah-langkah reproduksi membantu penyelidikan.

Berbagi dengan Pihak Ketiga

Informasi tidak diberikan kepada pihak ketiga kecuali jika diwajibkan oleh hukum. Fitur-fitur yang disediakan Apple seperti pembelian dalam aplikasi dan iCloud Drive juga tunduk pada Kebijakan privasi Apple.

Keamanan

File dan pengaturan PDF hanya ditangani sesuai kebutuhan aplikasi.

Informasi yang Anda Kelola

File PDF dan kata sandi dikelola oleh perangkat Anda, iCloud Drive, atau lokasi penyimpanan yang Anda gunakan. Jika Anda menangani PDF sensitif, aktifkan kode sandi perangkat, biometrik otentikasi, dan perlindungan akun iCloud.

Perubahan Kebijakan

Kebijakan privasi ini dapat diperbarui bila diperlukan.

Pemberitahuan Perubahan

Perubahan penting akan diumumkan di halaman ini atau di aplikasi. Versi terbaru selalu tersedia di halaman ini.

Kontak

Untuk pertanyaan privasi atau permintaan penghapusan, silakan hubungi dukungan.

Metode Kontak

Gunakan Masalah GitHub atau email. Saat memposting di tempat umum, jangan sertakan informasi pribadi atau konten PDF.
