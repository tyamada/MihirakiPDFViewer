# 見開きPDFビューア

公開サイトの使い方は [サポート](support_ja.html)、データの扱いは
[プライバシーポリシー](privacy_ja.html)をご覧ください。

ソース、対応環境、ビルド手順、機能、ライセンス、更新履歴は
[日本語README](https://github.com/tyamada/MihirakiPDFViewer/blob/testing/README_ja.md) と
[English README](https://github.com/tyamada/MihirakiPDFViewer/blob/testing/README.md) にまとめています。

設定の先頭とアプリ情報から、購入やログインなしでプライバシーポリシーを開けます。
空き容量は端末内表示専用で、共有する診断結果には含まれません。

サンプルPDFの案内は[日本語の集約ページ](https://tyamada.github.io/manga-prompt-kit/samples/ja/)、英語は[英語ページ](https://tyamada.github.io/manga-prompt-kit/samples/en/)をご利用ください。
