Patakaran sa Privacy

Patakaran sa Privacy

Ang MihirakiPDFViewer ay isang app para sa kumportableng pagbabasa ng mga PDF iyong device. Ipinapaliwanag ng page na ito kung anong impormasyon ang app humahawak at kung paano ginagamit ang impormasyong iyon.

Buod

Ang pangunahing diskarte sa privacy ng app.

Ang nilalamang PDF ay hindi ipinadala

Pagpapakita, paghahanap, pagtukoy ng pahina, at kaugnay na pagproseso para sa mga napiling PDF ay hinahawakan sa device.

Walang mga ad o analytics SDK

Hindi kasama sa app ang mga third-party na SDK para sa paghahatid ng advertising o pagsusuri ng pag-uugali.

Ang mga pagbili ay pinangangasiwaan ng Apple

Ang mga in-app na pagbili ay pinoproseso sa pamamagitan ng Apple's StoreKit. Ang app ay hindi direktang tumatanggap ng impormasyon sa pagbabayad.

Impormasyon na Hinahawakan ng App

Impormasyong maaaring gamitin ng bawat feature.

Mga PDF File

Binubuksan ng app ang mga PDF file na pinili gamit ang file picker. Ang tekstong PDF, metadata, at impormasyon ng pahina ay ginagamit para sa mga tampok sa pagtingin.

  • Ang mga PDF file ay hindi ina-upload sa isang panlabas na server.
  • Nilo-load ang mga PDF sa iCloud Drive ayon sa gawi ng system ng Apple.
  • Ang mga password para sa mga protektadong PDF ay ginagamit lamang para sa pag-unlock ng dokumento.

Mga Setting ng App

Mga setting ng display, setting ng cover, two-page view, app mga setting ng icon, at maaaring iimbak ang mga katulad na kagustuhan sa device.

  • Ginagamit ang mga setting para ibalik ang gawi ng app.
  • Ang mga setting ay hindi ipinadala sa isang server ng developer.

Mga Termino sa Paghahanap

Ang tekstong ipinasok sa paghahanap na PDF ay ginagamit upang maghanap sa loob ng binuksan ang PDF. Ang mga termino para sa paghahanap ay hindi ipinadala sa panlabas mga serbisyo.

Mga In-App na Pagbili

Maaaring gamitin ang status ng pagbili ng tip para sa post-purchase UI at mga pagbabago sa icon ng app.

  • Ang impormasyon sa pagbabayad ay pinamamahalaan ng Apple.
  • Ang developer ay hindi tumatanggap ng mga numero ng credit card o katulad na mga detalye ng pagbabayad.

Mga Tanong sa Suporta

Kung makipag-ugnayan ka sa suporta sa pamamagitan ng Mga Isyu sa GitHub o email, ang impormasyong ipapadala mo ay maaaring suriin kung kinakailangan tumugon o mag-imbestiga sa isyu.

  • Huwag magpadala ng PDF na nilalaman o personal na impormasyon maliban kung ito ay kinakailangan.
  • Ang modelo ng device, bersyon ng OS, bersyon ng app, at mga hakbang sa pagpaparami ay nakakatulong sa pagsisiyasat.

Pagbabahagi sa mga Third Party

Ang impormasyon ay hindi ibinibigay sa mga ikatlong partido maliban kung saan kinakailangan ng batas. Mga tampok na ibinigay ng Apple tulad ng Ang mga in-app na pagbili at iCloud Drive ay napapailalim din sa Patakaran sa privacy ng Apple.

Seguridad

Ang mga PDF file at setting ay pinangangasiwaan lamang kung kinakailangan para sa app.

Impormasyon na Pinamamahalaan Mo

Ang mga PDF file at password ay pinamamahalaan ng iyong device, iCloud Drive, o ang lokasyon ng storage na ginagamit mo. Kung hawakan mo mga sensitibong PDF, paganahin ang passcode ng device, biometric pagpapatunay, at proteksyon ng iCloud account.

Mga Pagbabago sa Patakaran

Maaaring ma-update ang patakaran sa privacy na ito kapag kinakailangan.

Paunawa ng mga Pagbabago

Ang mga mahahalagang pagbabago ay iaanunsyo sa pahinang ito o sa app. Ang pinakabagong bersyon ay palaging magagamit sa pahinang ito.

Makipag-ugnayan

Para sa mga tanong sa privacy o mga kahilingan sa pagtanggal, mangyaring makipag-ugnayan suporta.

Paraan ng Pakikipag-ugnayan

Gumamit ng Mga Isyu sa GitHub o email. Kapag nagpo-post sa pampublikong lugar, huwag isama ang personal na impormasyon o nilalamang PDF.
