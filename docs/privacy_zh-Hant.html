隱私權政策

隱私權政策

MihirakiPDFViewer 是一款用於輕鬆閱讀 PDF 的應用程式 您的設備。此頁面解釋了該應用程式的哪些訊息 處理以及如何使用該資訊。

總結

該應用程式的基本隱私方法。

PDF內容未寄出去

顯示、搜尋、頁面偵測及相關處理 選定的 PDF 在裝置上處理。

無廣告或分析 SDK

該應用程式不包含第三方 SDK 廣告投放或行為分析。

購買由 Apple 處理

應用程式內購買是透過 Apple 的 StoreKit 進行處理的。 該應用程式不會直接接收付款資訊。

應用程式處理的信息

每個功能可能使用的資訊。

PDF 文件

該應用程式開啟使用文件選擇器選擇的 PDF 文件。 PDF 文字、元資料和頁面資訊用於 觀看功能。

  • PDF 檔案不會上傳到外部伺服器。
  • iCloud Drive 中的 PDF 是根據 Apple 的系統行為載入的。
  • 受保護 PDF 的密碼僅用於解鎖文件。

應用程式設定

顯示設定、封面設定、兩頁視圖、應用程式 圖標設置，並且可以存儲類似的偏好 在設備上。

  • 設定用於恢復應用程式行為。
  • 設定不會傳送到開發人員伺服器。

搜尋詞

PDF 搜尋中輸入的文字用於在 PDF 搜尋中進行搜尋 打開 PDF。搜尋詞不會發送到外部 服務。

應用程式內購買

提示購買狀態可用於購買後 UI 和應用程式圖標更改。

  • 付款資訊由 Apple 管理。
  • 開發商不會收到信用卡號或類似的付款詳細資訊。

支援查詢

如果您透過 GitHub 問題或電子郵件聯絡支援人員， 您發送的訊息可能會根據需要進行審核 回覆或調查問題。

  • 除非必要，否則請勿傳送 PDF 內容或個人資訊。
  • 裝置型號、作業系統版本、應用程式版本和重現步驟有助於調查。

與第三方共享

資訊不會提供給第三方，除非 法律要求的情況下。 Apple 提供的功能，例如 應用程式內購買和 iCloud Drive 也受 蘋果的隱私權政策。

安全性

PDF 檔案和設定僅根據應用程式的需要進行處理。

您管理的訊息

PDF 檔案和密碼由您的裝置管理， iCloud Drive，或您使用的儲存位置。如果你處理 敏感 PDF、啟用設備密碼、生物識別 身份驗證和 iCloud 帳戶保護。

政策變化

本隱私權政策可能在必要時進行更新。

變更通知

重要變更將在此頁面或在 應用程式。此頁面始終提供最新版本。

聯絡方式

對於隱私問題或刪除請求，請聯繫 支持。

聯絡方式

使用 GitHub Issues 或電子郵件。在公共場所發文時， 不包含個人資訊或 PDF 內容。
