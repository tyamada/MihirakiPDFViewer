MihirakiPDFViewer 지원

MihirakiPDFViewer를 사용해 주셔서 감사합니다. 이 페이지에서는 PDF를 여는 방법, 두 페이지 보기, 검색, 확대, 암호 보호 PDF 처리 및 일반적인 문제 해결 방법을 설명합니다.

오른쪽에서 왼쪽으로 읽는 책과 일본어 출판물을 위해 만든 간단한 PDF 뷰어입니다.

FAQ

주제별로 정리한 자주 묻는 질문과 답변입니다.

기본

PDF 파일은 어디에서 열 수 있나요?

시작 시 표시되는 파일 선택기를 사용해 기기 또는 iCloud Drive에서 PDF를 선택하세요.

메뉴나 슬라이더가 보이지 않습니다.

PDF 이미지를 탭하면 도구 막대, 검색 막대, 슬라이더 표시를 전환할 수 있습니다.

페이지 사이를 어떻게 이동하나요?

화면을 스와이프하거나 메뉴를 표시한 뒤 화면 아래의 슬라이더를 사용하세요.

보기 및 조작

오른쪽에서 왼쪽으로 읽는 PDF를 지원하나요?

네. 앱은 PDF의 Direction 및 PageLayout 설정을 읽고 오른쪽에서 왼쪽 또는 왼쪽에서 오른쪽 읽기에 맞는 순서로 페이지를 표시합니다.

단일 페이지 보기와 두 페이지 보기를 전환할 수 있나요?

네. 표지 페이지 처리 방식을 포함해 표시 설정에서 보기를 변경할 수 있습니다.

확대한 PDF 안에서 이동할 수 있나요?

핀치로 확대한 뒤 길게 누르고 드래그하면 보이는 영역을 이동할 수 있습니다. 두 번 탭하면 확대가 초기화됩니다.

화면이 흐릿해 보이면 어떻게 해야 하나요?

설정에서 고화질 또는 선명도를 켜세요. 일부 기기에서는 이 옵션이 렌더링 부하를 높일 수 있습니다.

데이터와 보안

PDF 파일이 기기 밖으로 전송되나요?

PDF 보기는 기기에서 처리됩니다. 이 앱에는 처리를 위해 PDF를 외부 서버로 업로드하는 기능이 없습니다.

암호로 보호된 PDF를 열 수 있나요?

PDF에 사용자 암호가 필요하면 앱이 암호 대화상자를 표시합니다. 암호로 PDF가 잠금 해제되면 읽기를 계속할 수 있습니다.

앱 내 구입이 필수인가요?

아니요. 팁은 선택적인 후원 구입입니다. 앱의 읽기 기능은 팁을 구입하지 않아도 사용할 수 있습니다.

환경 및 문제

PDF가 열리지 않으면 어떻게 해야 하나요?

파일이 PDF인지, 손상되지 않았는지, iCloud Drive에서 완전히 다운로드되었는지 확인하세요.

왼쪽과 오른쪽 페이지가 예상과 다르면 어떻게 하나요?

방향, 두 페이지 보기, 표지 표시, 표지 모드 설정을 확인하세요. 일부 PDF는 메타데이터에 따라 수동 조정이 필요할 수 있습니다.

설정을 초기화할 수 있나요?

네. 설정의 옵션에서 초기화를 선택하면 기본 표시 설정으로 되돌리고 현재 문서를 닫습니다.

문제 해결

앱이 예상대로 작동하지 않으면 다음 항목을 순서대로 확인하세요.

앱 다시 시작

화면이 일시적으로 깨지거나 앱이 응답하지 않으면 앱을 종료한 뒤 다시 여세요.

PDF 파일 확인

다른 PDF를 열어 보세요. 특정 파일만 실패한다면 손상되었거나 완전히 다운로드되지 않았거나 다른 암호로 보호되어 있을 수 있습니다.

표시 설정 확인

두 페이지 보기, 표지 표시, 방향 또는 표지 모드를 변경하면 페이지 순서와 이동이 개선될 수 있습니다.

설정 초기화

설정의 초기화를 사용해 기본값으로 되돌리세요. 현재 열려 있는 PDF는 초기화 후 닫힙니다.

iOS/iPadOS와 앱 업데이트

OS와 앱을 최신 버전으로 업데이트하세요. 오래된 환경에서는 파일 연동이나 표시 문제가 있을 수 있습니다.
