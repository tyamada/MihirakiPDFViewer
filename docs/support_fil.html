FAQ

Mga karaniwang tanong at sagot, nakagrupo ayon sa paksa.

Mga pangunahing kaalaman

Saan ako makakapagbukas ng mga PDF file?

Gamitin ang file picker na ipinapakita sa paglulunsad upang pumili ng a PDF mula sa iyong device o iCloud Drive.

Ang menu o slider ay hindi nakikita.

I-tap ang PDF image para i-toggle ang toolbar, maghanap bar, at slider.

Paano ako lilipat sa pagitan ng mga pahina?

Mag-swipe sa screen, o ipakita ang menu at gamitin ang slider sa ibaba ng screen.

Pagtingin at Pagkontrol

Sinusuportahan ba nito ang kanan-papuntang-kaliwa na mga PDF?

Oo. Binabasa ng app ang Direksyon ng PDF at PageLayout mga setting at nagpapakita ng mga pahina sa naaangkop order para sa kanan-papuntang-kaliwa o kaliwa-papuntang-kanan na pagbabasa.

Maaari ba akong lumipat sa pagitan ng single-page at two-page view?

Oo. Maaari mong baguhin ang view mula sa display mga setting, kabilang ang kung paano pinangangasiwaan ang cover page.

Maaari ba akong lumipat sa isang naka-zoom na PDF?

Pagkatapos kurutin para mag-zoom, pindutin nang matagal at i-drag sa ilipat ang nakikitang lugar. I-double tap para i-reset ang zoom.

Ano ang dapat kong gawin kung mukhang malabo ang display?

I-on ang High Quality o Sharpness sa mga setting. Maaaring mapataas ng mga opsyong ito ang pag-load ng pag-render sa ilan mga device.

Data at Seguridad

Ang mga PDF file ba ay ipinapadala sa labas ng device?

Pinoproseso ang pagtingin sa PDF sa device. Ang app ay hindi kasama ang isang tampok na nag-a-upload ng mga PDF sa isang panlabas na server para sa pagproseso.

Maaari ko bang buksan ang mga PDF na protektado ng password?

Kapag ang isang PDF ay nangangailangan ng password ng user, lalabas ang app isang dialog ng password. Kung na-unlock ng password ang PDF, patuloy ang pagbabasa.

Kinakailangan ba ang mga in-app na pagbili?

Hindi. Ang mga tip ay mga opsyonal na pagbili ng suporta. Ang app Maaaring gamitin ang mga feature sa pagbabasa nang hindi bumibili ng tip.

Kapaligiran at Mga Isyu

Ano ang dapat kong gawin kung hindi bumukas ang isang PDF?

Tiyaking PDF ang file, hindi nasira, at ay ganap na na-download mula sa iCloud Drive.

Paano kung ang kaliwa at kanang mga pahina ay hindi tulad ng inaasahan?

Suriin ang direksyon, two-page view, cover display, at mga setting ng cover mode. Maaaring kailanganin ng ilang PDF manu-manong pagsasaayos depende sa kanilang metadata.

Maaari ko bang i-reset ang mga setting?

Oo. Piliin ang I-reset mula sa mga opsyon sa Settings to ibalik ang mga default na setting ng display at isara ang kasalukuyang dokumento.

Pag-troubleshoot

Kung hindi gumagana ang app gaya ng inaasahan, suriin ang mga item na ito sa pagkakasunud-sunod.

I-restart ang app

Kung pansamantalang masira ang display o huminto ang app pagtugon, isara ang app at buksan itong muli.

Suriin ang PDF file

Subukang magbukas ng isa pang PDF. Kung isang file lang ang nabigo, maaari itong masira, hindi ganap na mada-download, o maprotektahan ng a ibang password.

Suriin ang mga setting ng display

Pagbabago ng two-page view, cover display, direksyon, o maaaring mapabuti ng cover mode ang page order at navigation.

I-reset ang mga setting

Gamitin ang I-reset sa Mga Setting upang bumalik sa mga default. Ang kasalukuyang nakabukas na PDF ay isasara pagkatapos i-reset.

I-update ang iOS/iPadOS at ang app

I-update ang iyong OS at ang app sa mga pinakabagong bersyon. Maaaring may file integration o display ang mga lumang environment mga isyu.
