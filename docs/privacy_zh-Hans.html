隐私政策

隐私政策

MihirakiPDFViewer 是一款可在你的设备上舒适阅读 PDF 的 应用。本页面说明应用会处理哪些信息， 以及这些信息如何被使用。

摘要

应用的基本隐私处理方式。

PDF 内容不会被发送出去

所选 PDF 的显示、搜索、页面检测及相关处理 都在设备上完成。

没有广告或分析 SDK

应用不包含用于广告投放或行为分析的 第三方 SDK。

购买由 Apple 处理

App 内购买通过 Apple 的 StoreKit 处理。 应用不会直接接收付款信息。

应用处理的信息

各功能可能使用的信息。

PDF 文件

应用会打开通过文件选择器选中的 PDF 文件。 PDF 文本、元数据和页面信息会用于 查看功能。

  • PDF 文件不会上传到外部服务器。
  • iCloud Drive 中的 PDF 会按照 Apple 系统行为加载。
  • 受保护 PDF 的密码仅用于解锁文档。

应用设置

显示设置、封面设置、双页视图、应用 图标设置及类似偏好可能会存储 在设备上。

  • 设置用于恢复应用行为。
  • 设置不会发送到开发者服务器。

搜索词

在 PDF 搜索中输入的文本用于在 已打开的 PDF 内搜索。搜索词不会发送到外部 服务。

App 内购买

打赏购买状态可能用于购买后的界面 和应用图标变更。

  • 付款信息由 Apple 管理。
  • 开发者不会收到信用卡号或类似付款详情。

支持咨询

如果你通过 GitHub Issues 或电子邮件联系支持， 你发送的信息可能会在需要时被查看， 用于回复或调查问题。

  • 除非必要，请不要发送 PDF 内容或个人信息。
  • 设备型号、OS 版本、应用版本和复现步骤有助于调查。

与第三方共享

除法律要求外，信息不会提供给第三方。 Apple 提供的功能，例如 App 内购买和 iCloud Drive， 也受 Apple 隐私政策约束。

安全

PDF 文件和设置仅在应用需要时处理。

由你管理的信息

PDF files and passwords are managed by your device, iCloud Drive, or the storage location you use. If you handle sensitive PDFs, enable device passcode, biometric authentication, and iCloud account protection.

政策变更

本隐私政策可能会在必要时更新。

变更通知

Important changes will be announced on this page or in the app. The latest version is always available on this page.

联系

如有隐私问题或删除请求，请联系 支持。

联系方式

请使用 GitHub Issues 或电子邮件。在公开场所发布时， 不要包含个人信息或 PDF 内容。
