# サンプルPDFの公開コピー整理（2026-11-24）

## 削除と保持の判断基準

配信中の版と最新版が使用する配信先は保持する。製品版で配信停止した旧版だけの参照先は削除できる。最新版以外で配信状況を確認できない版の参照先は削除候補とし、最新版・公開Web・テストの依存を調べてから削除する。旧版が過去に参照したという理由だけで永久保持しない。

今回削除するのは各アプリのPages用 `docs/sample/tameshibu_*.pdf` の重複コピー。最新版のカタログはGitHub Releasesを参照し、公開Webの案内は共通のサンプル公開ページへ移行済み。旧版の端末内PDFは削除せず、旧Pages URLを使う旧版では再取得できなくなるため対応版への更新が必要になる。

現行の固定Release `tyamada/manga-prompt-kit` の `manga-pdf-20261103-v1`、両Androidリポジトリの `sample-manga-v1/v2` Release、一覧JSON・manifest・SHA-256・クレジット・ライセンスは変更しない。これらのReleaseを参照する配信版と取得済みキャッシュを維持する。アプリのソース・ストア設定・版番号を変更しない。

`testdata` の技術・回帰PDFは保持する。Android Utilityの漫画14件は、撮影・長時間検証・素材準備を検証済み外部キャッシュへ移行済みのためGit管理から除く。他の3アプリの `testdata` のPDFに削除対象はない。

削除前のパス・容量・Git blob IDは隣の `sample-pdf-retirement-2026-11-24.json` に記録する。Gitの過去コミットと旧作業コピーを保持し、履歴改変・タグ削除・Release添付削除は行わない。独立した長期保管の完了を意味しない。
