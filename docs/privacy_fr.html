Politique de confidentialité

Politique de confidentialité

MihirakiPDFViewer est une app permettant de lire des PDF confortablement sur votre appareil. Cette page explique quelles informations l’app traite et comment elles sont utilisées.

Résumé

L’approche de base de l’app en matière de confidentialité.

Le contenu des PDF n’est pas envoyé

L’affichage, la recherche, la détection des pages et les traitements associés des PDF sélectionnés sont effectués sur l’appareil.

Pas de publicité ni de SDK d’analyse

L’app n’inclut aucun SDK tiers pour la diffusion de publicité ou l’analyse comportementale.

Les achats sont gérés par Apple

Les achats intégrés sont traités avec StoreKit d’Apple. L’app ne reçoit pas directement les informations de paiement.

Informations traitées par l’app

Informations pouvant être utilisées par chaque fonctionnalité.

Fichiers PDF

L’app ouvre les fichiers PDF sélectionnés avec le sélecteur de fichiers. Le texte, les métadonnées et les informations de page du PDF sont utilisés pour les fonctions d’affichage.

  • Les fichiers PDF ne sont pas téléversés vers un serveur externe.
  • Les PDF dans iCloud Drive sont chargés selon le comportement système d’Apple.
  • Les mots de passe des PDF protégés servent uniquement à déverrouiller le document.

Réglages de l’app

Les réglages d’affichage, de couverture, de double page, d’icône d’app et les préférences similaires peuvent être stockés sur l’appareil.

  • Les réglages servent à restaurer le comportement de l’app.
  • Les réglages ne sont pas envoyés à un serveur du développeur.

Termes de recherche

Le texte saisi dans la recherche PDF sert à chercher dans le PDF ouvert. Les termes de recherche ne sont pas envoyés à des services externes.

Achats intégrés

L’état d’un achat de soutien peut être utilisé pour l’interface après achat et les changements d’icône de l’app.

  • Les informations de paiement sont gérées par Apple.
  • Le développeur ne reçoit pas les numéros de carte bancaire ni les détails de paiement similaires.

Demandes d’assistance

Si vous contactez l’assistance via GitHub Issues ou par e-mail, les informations envoyées peuvent être examinées si nécessaire pour répondre ou analyser le problème.

  • N’envoyez pas de contenu PDF ni d’informations personnelles sauf si nécessaire.
  • Le modèle d’appareil, la version de l’OS, la version de l’app et les étapes de reproduction facilitent l’analyse.

Partage avec des tiers

Les informations ne sont pas fournies à des tiers, sauf lorsque la loi l’exige. Les fonctionnalités fournies par Apple, comme les achats intégrés et iCloud Drive, sont également soumises à la politique de confidentialité d’Apple.

Sécurité

Les fichiers PDF et les réglages ne sont traités que dans la mesure nécessaire à l’app.

Informations que vous gérez

Les fichiers PDF et les mots de passe sont gérés par votre appareil, iCloud Drive ou l’emplacement de stockage que vous utilisez. Si vous traitez des PDF sensibles, activez le code de l’appareil, l’authentification biométrique et la protection du compte iCloud.

Modifications de la politique

Cette politique de confidentialité peut être mise à jour si nécessaire.

Avis de modification

Les changements importants seront annoncés sur cette page ou dans l’app. La dernière version est toujours disponible sur cette page.

Contact

Pour toute question de confidentialité ou demande de suppression, veuillez contacter l’assistance.

Méthode de contact

Utilisez GitHub Issues ou l’e-mail. Lors d’une publication publique, n’incluez pas d’informations personnelles ni de contenu PDF.
