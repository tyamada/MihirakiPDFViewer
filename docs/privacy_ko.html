개인정보 처리방침

MihirakiPDFViewer는 기기에서 PDF를 편안하게 읽기 위한 앱입니다. 이 페이지에서는 앱이 어떤 정보를 처리하고 그 정보를 어떻게 사용하는지 설명합니다.

요약

앱의 기본 개인정보 보호 방침입니다.

PDF 내용은 외부로 전송되지 않습니다

선택한 PDF의 표시, 검색, 페이지 감지 및 관련 처리는 기기 안에서 수행됩니다.

광고 또는 분석 SDK 없음

이 앱에는 광고 전송이나 행동 분석을 위한 타사 SDK가 포함되어 있지 않습니다.

구입은 Apple이 처리합니다

앱 내 구입은 Apple의 StoreKit을 통해 처리됩니다. 앱은 결제 정보를 직접 받지 않습니다.

앱이 처리하는 정보

각 기능에서 사용될 수 있는 정보입니다.

PDF 파일

앱은 파일 선택기로 고른 PDF 파일을 엽니다. PDF 텍스트, 메타데이터, 페이지 정보는 보기 기능에 사용됩니다.

  • PDF 파일은 외부 서버로 업로드되지 않습니다.
  • iCloud Drive의 PDF는 Apple 시스템 동작에 따라 로드됩니다.
  • 보호된 PDF의 암호는 문서 잠금 해제에만 사용됩니다.

앱 설정

표시 설정, 표지 설정, 두 페이지 보기, 앱 아이콘 설정 및 유사한 환경설정이 기기에 저장될 수 있습니다.

  • 설정은 앱 동작을 복원하는 데 사용됩니다.
  • 설정은 개발자 서버로 전송되지 않습니다.

검색어

PDF 검색에 입력한 텍스트는 열린 PDF 안에서 검색하는 데 사용됩니다. 검색어는 외부 서비스로 전송되지 않습니다.

앱 내 구입

팁 구입 상태는 구입 후 UI와 앱 아이콘 변경에 사용될 수 있습니다.

  • 결제 정보는 Apple이 관리합니다.
  • 개발자는 신용카드 번호나 유사한 결제 세부 정보를 받지 않습니다.

지원 문의

GitHub Issues 또는 이메일로 지원팀에 문의하면, 답변하거나 문제를 조사하기 위해 필요한 범위에서 보내신 정보가 검토될 수 있습니다.

  • 필요하지 않은 경우 PDF 내용이나 개인 정보를 보내지 마세요.
  • 기기 모델, OS 버전, 앱 버전, 재현 절차는 조사에 도움이 됩니다.

제3자와의 공유

법률상 필요한 경우를 제외하고 정보는 제3자에게 제공되지 않습니다. 앱 내 구입 및 iCloud Drive와 같은 Apple 제공 기능에는 Apple의 개인정보 처리방침도 적용됩니다.

보안

PDF 파일과 설정은 앱에 필요한 범위에서만 처리됩니다.

사용자가 관리하는 정보

PDF 파일과 암호는 사용자의 기기, iCloud Drive 또는 사용 중인 저장 위치에서 관리됩니다. 민감한 PDF를 다룰 때는 기기 암호, 생체 인증 및 iCloud 계정 보호를 켜세요.

방침 변경

이 개인정보 처리방침은 필요할 때 업데이트될 수 있습니다.

변경 안내

중요한 변경 사항은 이 페이지 또는 앱 안에서 안내됩니다. 최신 버전은 항상 이 페이지에서 확인할 수 있습니다.

문의

개인정보 관련 질문이나 삭제 요청은 지원팀에 문의해 주세요.

문의 방법

GitHub Issues 또는 이메일을 이용하세요. 공개된 장소에 게시할 때는 개인 정보나 PDF 내용을 포함하지 마세요.
