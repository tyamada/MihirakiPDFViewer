常見問題解答

常見問題和解答，按主題分組。

基礎知識

我可以從哪裡開啟 PDF 檔案？

使用啟動時顯示的檔案選擇器來選擇 來自您的裝置或 iCloud Drive 的 PDF。

選單或滑桿不可見。

點擊 PDF 圖像切換工具列、搜索 欄和滑桿。

如何在頁面之間移動？

在螢幕上滑動，或顯示選單並使用 螢幕底部的滑桿。

查看和控制

它支援從右到左的 PDF 嗎？

是的。該應用程式讀取 PDF 方向和頁面佈局 設定並在適當的位置顯示頁面 從右到左或從左到右的閱讀順序。

我可以在單頁視圖和兩頁視圖之間切換嗎？

是的。您可以變更顯示器的視圖 設置，包括如何處理封面頁。

我可以在縮放的 PDF 中移動嗎？

雙指開合縮放後，長按並拖曳即可 移動可見區域。雙擊可重置縮放。

如果顯示看起來模糊，我該怎麼辦？

在設定中開啟“高品質”或“清晰度”。 這些選項可能會增加某些設備的渲染負載 設備。

資料與安全

PDF 檔案是否傳送到裝置外部？

PDF 查看是在裝置上處理的。該應用程式 不包括將 PDF 上傳到 外部伺服器進行處理。

我可以開啟受密碼保護的 PDF 嗎？

當 PDF 需要使用者密碼時，應用程式會顯示 密碼對話框。如果密碼解鎖 PDF， 閱讀仍在繼續。

是否需要應用程式內購？

不會。小費是可選的支持購買。該應用程式的 無需購買小費即可使用閱讀功能。

環境與問題

如果 PDF 打不開怎麼辦？

確保文件是 PDF，未損壞，並且 已從 iCloud Drive 完全下載。

如果左右頁不符合預期怎麼辦？

檢查方向、兩頁視圖、封面顯示、 和封面模式設定。某些 PDF 可能需要 根據其元資料進行手動調整。

我可以重置設定嗎？

是的。從“設定”中的選項中選擇“重置” 恢復預設顯示設定並關閉 目前文件。

故障排除

如果應用程式未按預期運行，請按順序檢查這些項目。

重新啟動應用程式

如果顯示器暫時損壞或應用程式停止 響應，退出應用程式並再次打開它。

檢查 PDF 文件

嘗試開啟另一個 PDF。如果只有一個文件失敗，則可能 已損壞、未完全下載或受保護 不同的密碼。

檢查顯示設定

變更兩頁視圖、封面顯示、方向或 封面模式可以改善頁面順序和導航。
