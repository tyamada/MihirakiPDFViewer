Privacy Policy

プライバシーポリシー

MihirakiPDFViewerは、PDFを端末内で快適に閲覧するためのアプリです。 このページでは、アプリが扱う情報と、その取り扱い方針を説明します。

概要

アプリの基本的なプライバシー方針です。

PDFの内容は送信しません

選択したPDFファイルの表示、検索、ページ判定などの処理は、 原則として端末内で行われます。

広告・解析SDKは使用しません

本アプリは、広告配信や行動解析を目的とした第三者SDKを 組み込んでいません。

購入処理はAppleが扱います

アプリ内購入はAppleのStoreKitを通じて処理されます。 決済情報を本アプリが直接取得することはありません。

取り扱う情報

機能ごとに、扱う可能性がある情報を整理しています。

PDFファイル

ユーザーがファイルピッカーで選択したPDFを読み込みます。 PDFの本文、メタデータ、ページ情報は閲覧機能のために使用します。

  • PDFファイルを外部サーバーへアップロードしません。
  • iCloud Drive上のPDFは、Appleの仕組みに従って端末へ読み込まれます。
  • パスワード付きPDFのパスワードは、解除処理のために使用します。

アプリ設定

表示設定、表紙設定、見開き表示、アプリアイコンなどの設定を 端末内に保存する場合があります。

  • 設定はアプリの動作を復元するために使用します。
  • 設定情報を開発者のサーバーへ送信しません。

検索語句

PDF内検索で入力された語句は、開いているPDF内の検索に使用します。 検索語句を外部サービスへ送信しません。

アプリ内購入

応援機能の購入状況は、購入後の表示やアプリアイコン変更のために 使用されることがあります。

  • 決済情報はAppleが管理します。
  • 開発者がクレジットカード番号などを取得することはありません。

お問い合わせ

GitHub Issuesやメールでお問い合わせいただいた場合、返信や調査に 必要な範囲で、ユーザーが送信した情報を確認します。

  • PDF本文や個人情報は、必要がない限り送信しないでください。
  • 不具合報告には、端末名、OSバージョン、アプリバージョン、再現手順を含めると調査しやすくなります。

第三者提供

法令に基づく場合を除き、取得した情報を第三者へ提供しません。 アプリ内購入やiCloud Driveなど、Appleが提供する機能については Appleのプライバシーポリシーも適用されます。

安全管理

ユーザーのPDFと設定を、必要な範囲で適切に扱います。

ユーザー自身で管理する情報について

PDFファイルやパスワードは、ユーザーの端末、iCloud Drive、 またはユーザーが利用する保存先で管理されます。 機密性の高いPDFを扱う場合は、端末のパスコード、生体認証、 iCloudアカウントの保護設定を有効にしてください。

ポリシーの変更

必要に応じて、このプライバシーポリシーを更新することがあります。

変更の通知

重要な変更がある場合は、このページまたはアプリ内でお知らせします。 最新の内容は常にこのページで確認できます。

お問い合わせ

プライバシーに関する質問や削除依頼がある場合は、 サポート窓口からご連絡ください。

連絡先

GitHub Issuesまたはメールでお問い合わせください。 公開される場所へ投稿する場合は、個人情報やPDF本文を含めないでください。
