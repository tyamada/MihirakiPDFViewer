よくある質問

カテゴリ別に、よくある質問と回答をまとめています。

使い方

PDFファイルはどこから開けますか？

起動時に表示されるファイルピッカーから、端末内または iCloud Drive上のPDFファイルを選択できます。

メニューやスライダーが表示されません。

PDF画像をタップすると、ツールバー、検索バー、 スライダーの表示と非表示を切り替えられます。

ページ移動はどう操作しますか？

画面をスワイプするか、メニュー表示中に画面下部の スライダーを操作してください。

表示と操作

右綴じPDFに対応していますか？

対応しています。PDFのDirectionやPageLayoutを読み取り、 右綴じ・左綴じに合わせたページ順で表示します。

見開き表示と単ページ表示を切り替えられますか？

設定画面の表示設定から切り替えられます。 表紙あり/なしの扱いも調整できます。

拡大したPDFを移動できますか？

ピンチで拡大したあと、長押ししてからドラッグすると 表示位置を移動できます。ダブルタップで拡大率をリセットできます。

表示がぼやける場合はどうすればよいですか？

設定画面で「高画質化」や「シャープネス」を有効にしてください。 ただし、端末によっては描画負荷が上がる場合があります。

データ・セキュリティ

PDFファイルは外部へ送信されますか？

PDFの閲覧処理は端末上で行います。ファイルを外部サーバーへ アップロードして処理する機能はありません。

パスワード付きPDFを開けますか？

閲覧パスワードが設定されたPDFを開くと、パスワード入力 ダイアログが表示されます。正しいパスワードで解除できると 閲覧を続けられます。

アプリ内課金は必須ですか？

必須ではありません。チップ購入は開発を応援するための任意の 機能で、購入しなくてもアプリの機能は利用できます。

動作環境・不具合

PDFが開けない場合はどうすればよいですか？

ファイルがPDF形式であること、破損していないこと、 iCloud Driveから完全にダウンロード済みであることを確認してください。

ページの左右が期待と違う場合は？

設定画面でスクロール方向、見開き表示、表紙設定を確認してください。 PDF側のメタデータによっては手動調整が必要な場合があります。

設定を初期状態に戻せますか？

設定画面のオプションから「リセット」を選択すると、 表示設定を初期状態に戻し、現在のドキュメントを閉じます。

困ったときは

表示が崩れる、動かない、開けない場合は、次の順に確認してください。

アプリを再起動する

一時的な表示崩れや操作不能が起きた場合は、アプリを終了して もう一度起動してください。

PDFファイルを確認する

別のPDFで開けるか確認してください。特定のPDFだけ開けない場合は、 ファイル破損、未ダウンロード、パスワード違いの可能性があります。

表示設定を見直す

見開き表示、表紙表示、スクロール方向、表紙設定を変更すると、 ページの並びや移動方向が改善することがあります。

設定をリセットする

設定画面の「リセット」から初期状態に戻せます。リセット後は 現在開いているPDFが閉じられます。

OSとアプリを更新する

iOS/iPadOSとアプリを最新バージョンに更新してください。 古い環境では一部の表示やファイル連携が正しく動作しない場合があります。

不具合報告・お問い合わせ

解決しない場合は、再現手順と利用環境を添えてお問い合わせください。

GitHub Issues

不具合報告や改善要望はGitHub Issuesへ登録してください。 PDFファイルの内容に個人情報が含まれる場合は、添付しないでください。

GitHub Issuesを開く

公開リポジトリのURLが決まったら、このリンクをIssuesのURLへ 差し替えてください。

メール

個別に連絡したい内容はメールでお問い合わせください。 返信には時間がかかる場合があります。

support@example.com

送信先メールアドレスが決まったら、実際のサポート用アドレスへ 差し替えてください。

報告時に含めてほしい情報

端末名、iOS/iPadOSのバージョン、アプリのバージョン、 問題が起きたPDFの種類、再現手順、表示されたエラーメッセージを 分かる範囲で記載してください。
